Element Alert - テストページ

テスト1: 価格の変更

1,000円
セレクタ: #price
このボタンをクリックすると価格が変わります。

テスト2: カウンター

0
セレクタ: #counter
1秒ごとに自動でカウントアップします。

テスト3: ステータス変更

待機中
セレクタ: #status
ステータスがランダムに変わります。

テスト4: 子要素の変更

親要素の内容
孫要素: 初期値
セレクタ: #parent
親要素を監視すると、子要素・孫要素の変更も検知されます。

🔍 使い方

  1. Chrome拡張機能のアイコンをクリック
  2. 「要素を選択」ボタンをクリック
  3. このページ上で監視したい要素（例: 価格、カウンターなど）をクリック
  4. ポップアップを再度開いて「監視を有効にする」にチェック
  5. 「設定を保存」をクリック
  6. 上記のボタンをクリックして値を変更
  7. デスクトップ通知が表示されるはず！
